# 校园插画全站重建映射与验收

本文件记录 2026-09-12 本地重建的页面结构、素材分配和验证范围。截图保存在系统临时目录，不进入公开仓库。它只证明本地版本，不证明生产服务器已更新。

## 共享壳层

- 桌面：68px 顶栏、240px 分组侧栏、连续主工作区。顶栏展示当前班级、班级教学/家庭学习入口、真实保存状态和账户入口。
- 侧栏：今日、学生、教学、班级四组，可折叠；19 个模块都有入口，正式导航统一使用线性 SVG。
- 手机：品牌与保存状态、当前班级、学习场景组成紧凑顶部；底部保留首页、学生、作业、成绩、更多五个高频入口。
- 校园主题为唯一可见主题。玻璃主题只保留 `ThemeName`、配置状态和语义插画槽接口，没有切换入口。

## 业务边界

- 重建不改变账户隔离、只读演示、管理员权限、乐观版本保存、本机草稿、冲突处理和备份恢复。
- 听写仍以服务器确认成功为保存条件；失败不跳到下一位，未批改不算全对，请假和未参加不计错误，复听建立新任务。
- 家庭孩子和班级学生继续使用不同 context，家庭孩子不进入班级名册。
- 通知仍只生成和复制草稿；OCR、自动报词、AI 批改和玻璃主题仍未实现。

## 本地验收范围

- 自动布局覆盖 19 个模块的 1440、1280、1057、768、390、360 宽度，检查文档横向溢出、控件越界、遮挡、控制台错误和弹窗可用高度。
- 人工视觉重点检查首页、学生名单、作业追踪、听写批改，以及健康、成绩、档案、班干部等编辑弹窗。
- 功能回归继续覆盖双班长名单、家庭两个孩子、旧备份兼容、保存失败、409 冲突、只读模式和认证集成。
- 最终 `qa:strict` 共 115 项结果、117 张系统临时截图，失败数为 0；静态审计已同步识别新的工作区壳层。这证明所列本地宽度和演示数据通过，不代表真实设备、外部网络或生产环境已验收。
- C1–C6 人工复核后进一步修正了首页场景比例、手机首屏高度、作业零选择批量条和桌面听写保存位置。隔离测试工作区实际执行一次错词确认与“保存并下一位”，完成数 5→6 且进入下一名学生。

## 保留的维护风险

- `ClassroomApp.tsx` 和 `workbench-repair.css` 仍然偏大。本轮已经提取共享壳层、首页、页面族样式和独立听写模块，但其余业务页面仍有历史类名和局部样式依赖；后续应随真实需求继续拆分，不能为追求文件大小一次性重写稳定业务。
- 生产构建仍可能报告前端 chunk 超过 500KB。它是手机弱网性能风险，不影响本轮业务正确性。
- 本地浏览器和自动检查不等于真实 HTTPS、外部手机网络或生产数据验收。
