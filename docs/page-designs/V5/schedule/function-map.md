# 课程日程功能与界面保留

ScheduleHub现有班级课表和“我的日程与留痕”两个入口；候选把后者拆成日程及已完成记录两个工作面。TeacherAgenda现有标题直接进入编辑；候选阅读详情需独立设计后实现。

- class-timetable：班级课表页签；按月份周次查看课程及班级安排。
- personal-agenda：我的日程页签；查看当日待办和完成并留痕。
- work-log-library：工作留痕页签（拟从现有日程底部独立）；查看已完成工作记录。
- timetable-editor：编辑本周课表 / 手机编辑当天；编辑自定义教学日、节次、时间及课程。
- term-settings：学期设置；学年学期、起止月份与备注。
- event-editor：本周安排编辑；日期、类型、标题、详情。
- focus-editor：本周重点事项编辑；日期、重点、状态、待办。
- agenda-detail：日程查看详情（候选提出）；阅读完整日程及关联信息。
- agenda-editor：新增或编辑事项；日期时间、类型、学生、地点、说明、状态。
- work-log-detail：查看留痕 / 查看记录；阅读已完成事实与来源。
- work-log-editor：手动记录或编辑留痕；日期类型标题、学生、耗时及具体事实。

保留operations/workspace保存、班级隔离、时间顺序与关联学生校验、完成生成一条agendaId留痕、服务端确认后关闭、失败/冲突保留草稿。日程四状态与七类型完整保留。

课程支持1–7教学日、1–16节次，空课程不虚构；月内周次按1–7、8–14等分段，保持其他班级及其他周数据。旧F-15/O-15/A-15仅作为功能保留依据，不能代替本轮设计验收。
