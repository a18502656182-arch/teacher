# 课程日程：候选后的实施状态合同

日期：2026-09-15。C01三个主工作面获用户“确认”；C02八类详情/编辑工作面需另外确认。本文件是后续实施约束，不是已完成测试记录。

## 入口及返回

- 班级课表进入课表、学期、班级安排、重点事项编辑；取消回原月份/周次/手机教学日，不跳回默认周。
- 我的日程进入阅读详情，再显式编辑；新建复用编辑表单的空草稿。保存成功返回同一条详情，日期筛选保留。
- 工作留痕进入阅读详情，再显式编辑；手动记录复用空表单，来源标为手动。来源日程是只读关系，编辑不可擅自重关联。
- 完成并留痕通过现有operations实现，重复操作不产生第二条同agendaId记录。已完成日程显示查看留痕或补充留痕；已取消事项不显示完成动作。
- 各阅读详情必须展示完整正文，不能截断后无处展开；学生关联不等于长期评价，不放成绩、完成率等无时间范围指标。

## 同构状态与差异

| 工作面 | 同构变体 | 后续实际证据 |
| --- | --- | --- |
| 课表编辑 | 1–7教学日、1–16节次、空课程、长课程名、月末短周 | 5日/7日桌面及手机；增加、删除、清空、取消、保存 |
| 学期设置 | 起止月份、自由学期名称、备注长文 | 无效范围原位提示、有效保存、取消不写入 |
| 班级安排编辑 | 零条、新增、移除、多条、长说明 | 空态添加首条、编辑两条、移除后取消恢复 |
| 重点事项编辑 | 待处理/进行中/已完成 | 三状态原位切换；保存结果不占横条 |
| 日程详情 | 待处理/进行中/已完成/已取消、无学生、未填时间地点 | 对应动作可达，缺失值明确，不虚构数据 |
| 日程编辑 | 新建/修改、七类型、四状态、多学生 | 字段和最后按钮可达，校验时间顺序与当前班级学生 |
| 留痕详情 | 手动/来自日程、无耗时、无关联学生、长事实 | 阅读完整；无待办开关；来源缺失时不造关联 |
| 留痕编辑 | 新建/修改、耗时未填、长事实、多学生 | 原ID保存；来源关系不变；零耗时按现有语义处理 |

空态和同字段的新增状态复用已确认构图，不当作独立阅读页的替代；实现时若布局因状态发生结构改变，必须补独立候选。候选中的教学日/节次数只是示例，不得据此删减现有能力。

## 共用交互待实际验证

只读不显示可写假动作；保存中防重复，保存成功原位置更新；失败和409冲突保留草稿且给可恢复操作。成功轻反馈不采用推挤布局的大横条；真实错误和冲突不能被静默隐藏。脏关闭、删除确认、学生搜索选择器仍需单独实际验证，不因本轮候选齐全而声称弹窗已验收。

学生选择沿用搜索姓名/学号的多选流程，不把100+学生塞进普通下拉。手机需检查360/390宽、长文末尾与软键盘下的保存可达性；软键盘未实测时明确保留风险。
