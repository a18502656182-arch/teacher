# 现场功能与状态

来源：app/w/[token]/HealthCare.tsx，features/health/operations.ts；旧实施包F-09/O-09，逐页任务卡V3/health。唯一工作区核对，未改正式组件。

| 功能 | 现场行为 | 新设计位置 |
|---|---|---|
| 当前班登记 | 班ID+当前班学生ID过滤，优先级紧急/重要/一般排序 | 行动清单，优先提示不代表医疗判断 |
| 搜索与筛选 | 学生姓名/类型/摘要/行动/注意/场景检索；优先级、类型、场景独立筛选 | 紧凑工具栏，手机折叠筛选 |
| 分类 | 9种内置类别，其他可自定义30字 | 标签与编辑器 |
| 新增/编辑 | 学生必选，其余行动信息可空；摘要40字、行动/注意各180字、确认日期 | 主页面详情；编辑后置专项 |
| 选择学生 | 姓名/学号/小组搜索，输入后最多8个结果，不整班下拉 | 独立搜索选择 |
| 场景 | 6种内置，多选；自定义最多8项，操作层去重上限14 | 筛选和详情，编辑保留全部 |
| 联系人 | 从学生名单主要监护人取名/关系/电话，按主联系人与优先次序 | 单学生详情最小展示，主列表不暴露电话 |
| 删除 | 共享classroom:confirm危险确认，限定当前班记录 | 更多操作；取消不变 |
| 保存 | update后等persist确认；失败保留编辑，脏/保存中阻止离开 | 状态与恢复路径必须保留 |

不能把界面“仅班主任可见”文字当作已验证服务器权限；权限在正式接入时验证。候选只设计老师已录入的行动提示，不新增诊断、用药或风险评分。

待P01验证：当前列表无分页，100+登记必须有可达分页或内部滚动；主列表搜索当前不含学号（选择器包含）；失败后新增重试可能创建重复ID；persist抛错未捕获；脏草稿取消要求手动清空恢复，需明确放弃入口；持续409恢复不能困在编辑层内。这些是现场风险，非本轮已修复。

状态清单：正常3条、空班、无登记、无匹配、多条件、100+学生/多登记、长摘要/行动/自定义场景、无监护人、新增/编辑/删除确认、只读、校验、保存中、失败重试、持续409、脏关闭与切班。候选仅覆盖双端主状态，未覆盖的状态不能记通过。
