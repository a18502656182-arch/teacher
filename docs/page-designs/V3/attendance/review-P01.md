## 4. Material issues / 问题、证据与最小修正

### P1：月历把未确认的本机记录表述为已登记 — resolved

useAttendanceDesignController.ts 的 saveChanges 先 update，再 await save；calendar 直接读取同一 data.attendanceRecords。因此失败后新增或修改的记录仍被月历计入已登记/异常。function-map 明确要求月历依据已保存记录，失败不能表现为服务器已确认。普通失败截图已能看到本机统计随失败操作变更，源码给出了月历同样变更的完整路径。

最小修正：保留本机数据以便重试，但将 busy/unsynced 日期的月历标记与 aria 文案明确为“待同步”，解释其统计含本机改动；保存确认后恢复登记语义。或者单独读取确认保存快照。只需隔离控制器/展示层处理，不应借此重写正式业务。须验证失败、409、重试成功三个阶段。

复核结果：已打开 review-fix/390-save-failure-empty.png 和 1536-save-failure-empty.png，原本无当日记录的模拟保存失败后显示“待同步”，月历说明明确当前日期包含本机待同步改动。源码同时替换 aria 文案；busy/unsynced 路径覆盖失败与409。final-interactions/interactions.json 的桌面/手机 new-unsaved-calendar-date-pending 与 calendar-ack-after-retry 均通过，确认重试成功后恢复登记语义。问题已解决，未改正式 operations。

### P2：手机四态达标，部分其他触控范围未达 44×44 — resolved

AttendanceDesign.module.css 手机日期按钮仍为 min-width:32px；选择 label 所在网格列为 28px；日期、搜索和备注输入有 40px 高度声明。现有 capture 的 statusTargets 只测四态，因此不能据此推论所有手机交互达标。360 月历七列还需实测日期按钮宽度。

最小修正：局部扩大按钮/选择 label 的真实点击范围，输入高度至少 44px；极窄日期工具栏允许有组织的换行，不压缩日期文本或四态文字。补充 360/390 的目标矩形及相邻目标无重叠证据。共享壳层不在本次修正范围。

复核结果：已打开 review-fix 的 390 普通/月历和 review-narrow 的 360 普通/月历。日期工具栏保留单行，今天入口移入月历成为“回到今天”，功能仍可达。两份 capture.json 的 22 个手机场景记录 974 个目标矩形，没有宽或高小于 43.9px 的目标；无页面横向溢出、挤字记录。日期按钮、输入、搜索、筛选、选择 label、备注和月历日期均已扩大，截图未见相邻目标重叠。此统计针对隔离页面已采集目标，不延伸到共享壳层或所有设备。问题已解决。

检测器 27 项均为 advisory：20 个局部颜色、5 个字号、2 个圆角。它们不是 27 个已证明视觉缺陷。色彩与 C01 四态方向相符，不应为清空检测输出更换配色或批量污染全局规范。月历 8/9px 附注偏小，作为后续可读性观察项；当前完整日期/登记信息有 aria 文案，不因此新增无止境美化轮次。

### P2：隐藏标签溢出内部名单，产生纵向空白尾部 — resolved

补充全长采集由执行者发现：桌面 normal 的 body 高约 1127px、scrollHeight 2457px，手机 body 高约 1113px、scrollHeight 3830px。它是实际文档滚动边界异常，不仅是截图出现空白。之前的 no-overflow 只检查横向，不能用来关闭此问题。

独立源码核对支持原因：逐行当日备注的 .srOnly 标签为 position:absolute，未设置 inset；.student、.note、.studentList 没有定位上下文，后段行的绝对定位标签可能越过内部滚动区，以更远的包含块计算溢出。最小修正是 .student 添加 position:relative，把行内隐藏标签的包含块留在名单内；保留标签与 htmlFor，不通过删无障碍内容解决。执行者负责修复及对照 document/body/scrollHeight、名单末行/分页可达性和全長截图，本报告不擅自改源代码。

复核结果：仅增加 .student{position:relative}。已读取 supplement-final/supplement.json 并打开 1536-normal-full.png、390-normal-full.png、390-students-105-full.png。桌面普通和长备注 body=1127.796875、scrollHeight=1128，原 2457/2541px 的空白尾部消失；手机普通/长备注/105人 body=1113、scrollHeight=1195，剩余 82px 与预览专用 students-preview.css 的 .design-controls 底边距一致，原 3830/3891px 异常消失。105人手机最后一页与分页在全长证据中可见。此项已解决；全长截图用于边界/可达性，固定定位底栏在长图中的位置不能当作新的首屏构图证据，正常视口仍以 final-main 为准。
