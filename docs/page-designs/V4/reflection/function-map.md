# 源码功能映射与保留
来源：ClassroomApp.tsx Reflection(3873)、ReflectionWithExam(3882)、MobileSecondaryPage(837/2089)；features/reflections/operations.ts；旧feature-preservation.csv F-12。旧完成仅为保留依据。

|功能|当前行为|新设计落点/验证要求|
|---|---|---|
|考试选择|桌面考试库搜索/科目/年月/排序/分页10；手机select|上下文切换考试入口；长库须可搜索分页，不丢筛选|
|学生选择|当前班，搜索姓名/学号/反思文本，桌面12/页、手机10/页|队列搜索、状态和重点跟进过滤、分页；无结果不得回退到无关学生编辑器|
|考试背景|完整/部分/未录成绩，重点跟进|标为本次考试，逐科/录入范围可查看；不以原始均分作长期评价|
|草稿填写|日期、主要问题、原因、行动、家长话、教师跟进|双端五字段与日期；主要问题保存草稿也必填；其余可选|
|保存草稿|本机应用等待workspace确认；不生成归档|原位草稿/保存状态；未确认不能伪称服务器已保存|
|完成归档|upsert反思，新增/更新关联内部沟通记录，移除当前考试该学生重点跟进|保留按钮与结果；重复完成复用reflectionId/recordId，禁止重复新增；明确不会自动发送|
|编辑已存|桌面选学生载入；手机已保存反思检索/详情/复制/编辑|列表/已保存视图必须可达，不能只实现新建表单|
|切换离开|脏草稿确认；只读禁止写|考试/学生/返回/关闭一致守卫，保存中禁重复|
|空与失败|无考试/无学生/字段错误/服务器失败/冲突|P01独立合成场景；失败保留草稿和恢复入口|
