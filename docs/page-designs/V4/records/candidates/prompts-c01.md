# 家校沟通 C01 ImageGen提示词

## 桌面

为中国小学班主任工作台生成一张完整、清晰可读的桌面家校沟通UI独立候选图，1536×1024横向。附图1是当前真实页面，只作为功能和示例文案依据；附图2是校园视觉参考，不复制学生名单构图。白纸工作面、深海军蓝中文字体、青绿主命令、浅蓝分组、柔和粉笔绿通知侧栏；精细水彩信封与便签仅占标题右侧一小块。明确是操作台，不是营销页。真实字体比例：主标题34px，正文16px，次要14px，紧凑搜索高36px宽270px和下拉，不要巨大输入框。左侧244px常规导航栏：今日工作台、作业追踪、听写与复习、考勤与请假、学生名单、成长档案、健康与照护、家校沟通（选中）、成绩分析。上方72px共享栏：班主任工作台 / 三年级2班 / 班级教学 / 已保存 / 账户与班级，不要虚构老师姓名。主区域边距30px。标题家校沟通，说明‘先看跟进约定，再回顾沟通事实。’，小字‘3条沟通记录 · 2条待跟进’，右侧主要按钮‘新增沟通记录’。下面一行紧凑‘搜索学生或沟通内容’、‘全部类型’，状态文字tabs‘全部3 / 待跟进2 / 已跟进1 / 已归档0’。内容是68%宽沟通时间线与32%宽通知草稿工作区，切忌一堆圆角卡片。左侧‘待跟进’分组有两条连续平铺记录，细横线分隔；每条左为日期，右为姓名、类型/渠道、沟通事实一句、家长反馈一句、突出但柔和的下一步。第一条2026-09-15 学生01 作业跟进·微信，‘与家长核对阅读作业的完成安排。’、‘反馈：晚间可陪同阅读。’、‘下一步：约定9月17日再交流阅读情况。’右上小状态待跟进，右下文字‘查看详情’箭头。第二条2026-09-14 学生02 谈心记录·电话，‘交流孩子在小组活动中的表达情况。’、‘反馈：家长愿意继续观察。’、‘下一步：下周了解孩子的参与感受。’。下面‘已跟进’一条较紧凑：2026-09-12 学生03 表扬记录·面谈，‘向家长分享孩子主动帮助同伴的具体表现。’，小状态已跟进，‘查看详情’。不要编造逾期计算、健康分、发送统计、AI总结。跟进日期是老师写下的文本，不做倒计时提醒。右侧浅绿连续工作区标题‘通知草稿与回执’，小文字按钮‘新建草稿’，必须清楚写‘复制后由老师自行发送，系统不自动外发。’两段平铺非嵌套卡片：第一段标签‘草稿’，标题‘本周阅读安排’，‘班级群 · 全班家长’，日期2026-09-15，内容‘请家长与孩子共同确认本周阅读安排，周五交流阅读感受。’，主要文字动作‘复制通知’，次要‘记录回执’与‘更多’。第二段标签‘已记录回执’，标题‘阅读反馈提醒’，‘私聊 · 学生01家长’，内容‘请交流孩子近期的阅读感受。’，反馈‘回执：家长表示已了解。’，同类动作。绝不要‘已发送’或自动发送按钮。底部极小注记‘独立候选 · 合成示例’，正式界面风格完整精细，不放技术说明。

## 手机

生成一张中国小学班主任‘家校沟通’完整手机UI独立候选，逻辑宽390高844，输出高分辨率竖图853×1844左右。参考附图的中文字体、青绿/深蓝/浅蓝校园颜色与水彩信封风格，但必须独立手机重排，不能把桌面压窄。白纸平铺、细分隔线，不使用卡片套卡片，不要巨大输入框。顶部64逻辑px简洁栏：返回箭头、家校沟通、三点更多。以下标题区紧凑：三年级2班，小字‘3条记录 · 2条待跟进’，右侧70px小幅水彩信封便签插画且不要写装饰标语。接下来主导航两个文字标签：‘沟通记录 3’选中青绿下划线，‘通知草稿 2’未选。通知页功能存在但当前画面不展示草稿内容，让沟通记录首屏即可看到。紧凑搜索一行：‘搜索学生或沟通内容’，右侧小按钮‘筛选’，输入高38逻辑px不要宽大厚重。下一行状态文字tabs‘全部3 / 待跟进2 / 已跟进1’，可通过筛选查看已归档。随后标题‘待跟进’右侧文字主动作‘＋ 新增记录’。连续两条平铺记录，非边框卡片。第一行身份‘学生01’右‘待跟进’小暖橙标签；次行14逻辑px‘09-15 · 作业跟进 · 微信’；正文‘与家长核对阅读作业的完成安排。’；次要正文‘反馈：晚间可陪同阅读。’；柔和淡杏色一行下一步‘约定9月17日再交流阅读情况。’，右侧独立小chevron详情入口。第二条‘学生02’待跟进，‘09-14 · 谈心记录 · 电话’，正文‘交流孩子在小组活动中的表达情况。’，反馈‘家长愿意继续观察。’，下一步‘下周了解孩子的参与感受。’。再往下已跟进分组一条紧凑记录：学生03 已跟进，‘09-12 · 表扬记录 · 面谈’，‘向家长分享孩子主动帮助同伴的具体表现。’并有详情箭头。每条正文16逻辑px，姓名17，次要13-14，清晰非压缩小字。底部固定轻盈导航：首页、学生、作业、成绩、更多（更多选中），在底部保留空间，内容不被挡住。极小‘候选 · 合成示例’。不要编造发送成功、不发消息、不出现已发送。不要逾期倒计时、沟通评分、家长配合率，不要把跟进文本变成事实不存在的自动提醒。详情/编辑按入口保留，当前图是主列表。中文文案准确，视觉成熟、安静、层级清楚、紧凑有留白。
