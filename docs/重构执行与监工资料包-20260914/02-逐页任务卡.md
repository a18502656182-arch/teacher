# 19页执行卡
路径均相对 app/w/[token]/；符号位置按基线实际核对，执行前再定位。标“延展”的页面没有独立用户原图；其设计由本卡规定，在对应人工门槛确认。每页先读图/代码→改视图和局部CSS→批量检查→修复→提交证据→监工检查。

## 01 V1 / dashboard / 今日工作台
- 源码入口：features/dashboard/DashboardView.tsx + DashboardView.module.css。
- 依据：C1/C5直接。
- 桌面目标：待办左＋教室场景右；课程与听写形成第二层；班务提醒收束底部。
- 手机目标：日期/横幅→待办→课程→常用入口→提醒。
- 必须保留与测试：保留read-model事实与跨班隔离；空课日不补课程。
- 视觉否决项：场景主体足够大；浅黄/蓝/绿分区有主次；不再小图漂在蓝底。
- 交付：desktop/mobile实际图及对比、对应交互状态证据、变更提交、监工报告。本页结束即本门结束，必须人工暂停。
