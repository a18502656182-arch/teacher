## 启动顺序
1. 新开“监工”对话，绑定同一本地项目，粘贴 06-监工启动提示词.md。它先核对环境和共享检查点，不写产品代码。
2. 新开“执行”对话，绑定唯一开发目录，粘贴 05-执行启动提示词.md。先执行 V1，完成后停在人工审核。
3. 将两个对话链接互相提供。工具可用时直接收发检查通知；工具不可用时，执行者每页提交后停在监工检查点，由你在监工对话说“检查最新检查点”，然后把结论带回执行对话。
4. 门槛完成时使用 07-人工审核与恢复提示词.md。默认先首页、再每三页人工审核。无需重复全部历史。
5. 两个对话不同时修改产品源码。监工只写 supervision/reviews/；执行者管理源码、账本、checkpoint.json 和 Git。
