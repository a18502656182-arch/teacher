# 证据与验收
每页检查点必须记录：ID、门槛/页面、产品commit、变更文件、参考ID、设计差距、实际URL、采集时间、viewport、数据场景、桌面/手机截图路径及SHA256、对比图、测试命令/退出码/日志、未解决问题、监工报告、下一动作。
持久证据放docs/visual-baseline/current和comparisons，临时图放.qa-shots。演示页只能验证只读视觉，保存链路须隔离的合成数据环境；不能操作真实班级数据来做演示。
对比：完整原图等比展示＋实际图保留各自原始尺寸标注；单独提供同一CSS视口的实际桌面/手机图。参考手机稿为长图，不能拉伸到390×844或截掉底部假装同高；用首屏＋全页说明层次。参考原生像素不等于CSS像素。
两张比较图必须分别标注desktop/mobile，不接受同一文件重复填充。后续无独立原图页面，对比已批准母版并说明延展部分，不得标“像素级还原C3”。
必须真实打开图片，不能仅验文件存在。代码检查、渲染证据和审美判断分栏记录。

## 逐项判定（不使用总分抵消失败）
1. 主焦点与任务次序是否符合本页卡？
2. 插画主体可辨、面积有作用、裁切合理，无小图漂浮在大空底。
3. 模块主从、标题/正文大小、色彩分区、留白与参考关系成立。
4. 列表保持效率，状态文字完整，主次操作可分辨。
5. 手机真正重排；返回、底栏、粘性按钮不遮挡内容。
6. 空状态不造学生/日期/统计；长姓名、105人、长词/大词量可操作。
7. 保存失败/冲突仍保留草稿，只读入口无写入。
8. 未扩大到家庭教育、权限、数据库迁移等范围。
9. 截图、报告、测试是否同一产品版本；缺项标未验证。

## 命令（在项目根）
npm.cmd run qa:visual-baseline
npm.cmd run qa:visual-capture -- --gate V1
npm.cmd run qa:visual-gate -- --gate V1
npm.cmd run lint
npx.cmd tsc --noEmit --pretty false --incremental false
npm.cmd run qa:strict
npm.cmd run build
npm.cmd test
按本门替换V1。遵守项目必做检查；纯文档资料包不需重复全业务测试。每页针对变更检查；共享层变动与门槛提交按AGENTS完成构建/严格QA。测试记录复用同一未变产品提交的结果，不无意义重跑。
当前机器检查不能验证“用户真的说过通过”、图片语义与审美相似；监工必须独立读图、核对批准消息。
