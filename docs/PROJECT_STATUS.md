## 已知风险与未验证项

- 当前前端构建仍有超过 500KB 的 chunk 警告，功能不受阻，但手机弱网性能存在风险。
- 真实 JPG/PNG/PDF 的 AI 识别质量、超时与错误恢复未在正式 API Key 下验证。
- 完整“导出→清空/更换环境→恢复→再次保存”灾难恢复闭环仍需在隔离环境演练。
- 管理员永久删除等不可逆流程不应使用正式用户数据试错。
- 历史服务器使用 HTTP 兼容开关；功能兼容不等于传输安全，正式运营仍应使用 HTTPS。
- Git 推送状态和服务器部署状态必须分开记录。
