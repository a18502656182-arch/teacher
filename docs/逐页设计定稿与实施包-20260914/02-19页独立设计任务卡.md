# 19页独立设计任务卡
以下继承实际源码定位与功能边界，但不继承旧包“按首页延展即可”的验收。每一页需要独立候选、可运行稿和D/R批准。没有原始参考的页面，其独立设计稿必须新建并由用户确认。所有源码位置在接手时复核。

## V1 / dashboard / 今日工作台
- 源码入口：features/dashboard/DashboardView.tsx + DashboardView.module.css。
- 依据：C1/C5直接。
- 桌面目标：待办左＋教室场景右；课程与听写形成第二层；班务提醒收束底部。
- 手机目标：日期/横幅→待办→课程→常用入口→提醒。
- 必须保留与测试：保留read-model事实与跨班隔离；空课日不补课程。
- 视觉否决项：场景主体足够大；浅黄/蓝/绿分区有主次；不再小图漂在蓝底。
- 最低关键状态盘点：今日班务正常；今日无课；空班首次使用；多条待办与长提醒。
- 本页设计交付：dashboard-desktop、dashboard-mobile两个独立基础画面＋适用关键状态图；候选生成提示、完整文案、功能映射、真实设计组件、素材清单、几何与断点规范。
- 不可省略：无独立手机原图时先设计手机稿并请用户确认，不能拿旧手机实物作新设计目标；表中的“延展”只说明风格来源，不构成批准。
- 当前处理：保留既有历史批准；补状态盘点和共享变更回归；若要重新设计先单独明确其范围。
