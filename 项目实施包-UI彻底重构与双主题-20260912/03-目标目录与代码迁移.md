# 目标目录与代码迁移

以下路径是拟建，不代表当前已经存在；入口和API URL保持。具体文件名允许合理微调，职责和依赖方向不可倒置。

```text
app/w/[token]/ClassroomApp.tsx          最终只协调数据、权限、路由和壳层
app/components/workbench/shell/        顶栏、导航、手机返回层级
app/components/workbench/ui/           Button、Field、Dialog、Picker等
app/components/workbench/layouts/      MasterDetail、TaskWorkspace、EditorWorkspace
app/components/workbench/theme/        contracts、tokens、artwork、ThemeProvider
app/components/workbench/theme/campus/ 校园token与材质
app/components/workbench/theme/glass/  接口说明和内部验证配置，未公开
app/w/[token]/features/<module>/       controller、view、styles.module.css
lib/workbench/                         抽取的纯计算与归属辅助，不包含JSX
lib/classroom.ts lib/dictation.ts       保持数据契约
db/ app/api/                          默认保持
tests/                                业务回归和新增行为验证
```

## 依赖方向

feature controller→现有服务/纯函数；view→controller props+共享UI；共享UI→主题契约。theme不能导入workspace、请求API或控制业务路由。CSS Modules负责页面局部，token是唯一主题值来源；全局只放reset/字体/无障碍/根变量。

## 具体抽取步骤

1. 定位ClassroomApp中的normalizeData、scopeClassSettings、removeStudentRelations、updateClassStudents及日期/成绩计算；先保留算法，移动到明确命名模块，替换import并对原输入输出做回归。
2. 盘点workspaceRef、revisionRef、serverRevisionRef、dirtyRef、saveInFlightRef、saveQueuedRef、pendingDictationDraftRef和localStorage读写。第一次抽取保持闭包、排队和调用顺序，不把所有ref改成普通state。
3. 将save与commitWorkspace作为两个操作显式暴露，readOnly和冲突保护都在操作层保留。数据层抽取完成后再处理UI按钮映射。
4. 为单个feature建立controller，集中筛选、选择、草稿、打开编辑和提交事件。桌面/手机只改变视图，不能各自再写fetch或修改记录算法。
5. 同一个controller在workspace级或feature级只实例化一次。resize/主题变化不通过key导致remount，不丢失编辑内容。
6. 按模块动态import重型视图。依赖检查防止导入模块索引又把所有模块打进首页；记录构建分包实际变化。
7. 每一族完成后删除原function和该页旧mobile分支。不能保留两个同功能分支用display:none遮住。

## 新旧隔离的可执行选择

默认：迁移期间独立开发预览承载新壳层和组件基准，生产入口继续保留稳定页面；feature通过受控迁移标记逐个接入同一workspace store。标记仅开发迁移使用，不公开两套网站。
注意：CSS Modules不阻止旧全局选择器命中后代。不能只新建module.css就宣称隔离。
接入前把旧页面样式限制到[data-ui-generation="legacy"]作用域，并逐段检查html/body/:root/portal及祖先选择器。旧token改放legacy根，不让旧body布局污染新壳层。可使用AST工具协助，不使用简单字符串前缀替换全部CSS。
旧弹窗portal必须挂到所属legacy根或显式标记；新弹窗统一portal根只消费新token。不能让两个焦点管理器同时处理一个弹窗。
@layer仅作为辅助组织，不能修复所有未分层旧规则或!important。迁移页在旧CSS启用/移除两种开发预览中对比，应无视觉差异。

## 完成退出条件

layout.tsx不再导入workbench-repair.css及废弃校园覆盖文件；所有模块DOM无homework-bootstrap-shell/旧版结构类；ClassroomApp不再含全部页面实现；无旧selector兼容异常名单。保留旧业务名称不等于保留旧结构类，纯数据兼容函数不应删除。
scripts/layout-audit.mjs和rendered-html.test.mjs当前读取旧文件/符号，迁移时更新到可观察行为/新结构，不保留空旧文件来骗测试，也不删掉失败断言降低检查。
