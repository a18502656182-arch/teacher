# 插画生产与参考图用法

本包复用用户已有C1–C6、G0–G5原图作为视觉权威，没有额外生成一套未经确认的概念图。现有七张WebP复制在assets/incumbent，仅为可评估素材，不强制保留。主要素材在明确容器比例之后生产，避免先生成大量漂亮但无法排版的图片。

## 资源生产顺序

1. 逐张打开参考，记录笔触、光照、色彩、透视、主体位置。首批选校园课桌/窗光、词卡/铅笔、学生名册、作业本四个主题。
2. 先做一张风格母样，以现有校园参考为输入；不含人物、动物、UI、假按钮、口号和学生数据。
3. 母样通过实际页面容器检查后，用同风格生成桌面横幅、手机横幅、侧栏竖图与空态。不要从概念图裁一整块假UI塞进页面。
4. 产物拆为独立asset；必要的透明背景由图像工具正确处理，不能把白底图硬乘色造成脏边。
5. 用imagegen时读取当前imagegen skill；保存原始产物到本地忽略目录，webp/avif优化到public/art并登记。
6. 检查像素、裁切、颜色、边缘、透明度和文字禁区。标题由HTML呈现，不让生成图承担真实课次/日期/词语。
7. 同图在1536、1280、390、360检查；大图优先正确尺寸，非首屏lazy，主场景避免懒加载造成首屏空洞；width/height预留防布局跳动。

## 计划素材角色

|角色|构图与用途|手机策略|
|---|---|---|
|home.scene|教室窗光、黑板、课桌，宽幅；文字安全区独立|单独横幅，主体保留|
|dictation.context|词卡和铅笔，主体偏右，文字左侧|短横幅或局部裁切|
|student.detail|名册与学习记录，辅助栏顶端|档案页短页头|
|homework.context|作业本/课本，主体偏右|任务详情局部|
|assessment.context|试卷、尺、批注笔|分析页页头|
|planning.context|课程表、黑板、日历|日程视图局部|
|care.context|温和课桌与行动便笺，无病症符号|私密详情小图|
|communication.context|信纸/便笺，无‘已发送’暗示|记录页局部|
|organization.context|座位图/岗位安排纸|配置页局部|
|family.context|家庭学习桌、两份可区分文具，不画孩子头像|家庭首页|
|empty.first-use|书本与空白记录页|引导一步操作|
|empty.no-results|简洁书签或查找材料|小型，不占满屏|

允许同族复用，但不能十二个角色都指向词卡。未生产素材在asset-plan.csv中保持planned，不能改成ready。导入public前核对license/来源，用户参考不默认授权公开上传GitHub。

## 生成提示词模板

“为班主任日常工作台制作独立校园水彩插画素材。沿用附图的暖白纸色、浅蓝、粉笔绿、少量暖黄、自然晨光和细腻水彩笔触。主题【角色物件】，构图【主体位置/比例】，保留【文字安全区】。无人物、无动物、无网页UI、无按钮、无口号、无真实文字、无水印。素材将放入【实际像素容器】；画面边缘【透明/自然暖白融合，按工具支持】。不要生成整张网站效果图。”

产出后用真实浏览器判断是否融合。‘已经调用图片生成工具’不是视觉通过证据。

## 图中错误必须纠正

- 所有日期/学生/数字从真实数据来；保存状态动态。
- 补齐19导航；作业只保留一个主新增入口；勾选与当前查看不同。
- G图中的家长提交、外部消息、语音耳机含义不能推导新增门户/自动报词。
- C图复习开关只有在真实创建复习任务语义明确时才提供；不照搬空开关。
- C图口号、错误分页及不一致词数不照抄；图的空间组织和插画气质继续保留。
