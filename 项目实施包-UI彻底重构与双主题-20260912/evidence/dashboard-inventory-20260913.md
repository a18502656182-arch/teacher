## 已有行为

| 区域 | 数据来源 | 动作 |
| --- | --- | --- |
| 今日优先事项 | 当前班作业状态、当前班听写待批改 | 打开作业、考勤或听写；主按钮按作业、听写、考勤顺序选择。 |
| 今日安排 | 当前班当日未完成/未取消的 `teacherAgenda` | 打开完整课程日程模块。 |
| 听写摘要 | 当前班截至今天且未归档的班级听写任务 | 显示已批改、待批改、错词次并进入听写。 |
| 值日岗位 | 当前活动班已归一化到根字段的值日岗位 | 显示前4个启用岗位并进入值日。 |
| 学生近况 | 当前班学生的汇总成绩、考勤与作业字段 | 显示前4名并进入成长或全部学生。 |
| 家庭学习 | 未归档家庭孩子数量 | 切换到家庭场景并进入听写；孩子不混入班级人数。 |
| 手机账户 | `MobileHome` 外层唯一补充按钮 | 打开共享 `AccountCenter`，不维护第二套账户状态。 |

桌面和手机都渲染同一个 `Dashboard`，手机只增加账户入口；模块切换统一经过 `openModule`，同步更新 `?page=`，并遵守听写未保存离开保护。首页本身没有写入、编辑器或自有浮层，只负责读取和导航；全局只读/演示提示由工作台壳层展示。

## 已确认缺口

- “今日安排”只读取教师个人事项，没有读取当天课程表，因此当前文案“课程与班务按时间推进”覆盖范围大于数据事实。
- 待处理作业按任务状态对象直接计数，没有再按当前名册ID过滤；旧备份若保留已删除学生状态，首页数字可能偏大。
- 待跟进沟通数量只按状态统计，没有按当前班过滤，可能把另一班记录算入当前首页。
- 学生近况读取学生汇总字段，无法说明具体事实日期或来源；点击单个学生只进入成长模块，没有携带所点学生上下文。
- 优先按钮没有逾期层级，也没有把课程、值日或沟通跟进纳入优先级。空态、长标题、两班100人和上述数字来源尚未按A-01重新做浏览器证据。
- 当前展示仍位于共享 `components/campus` 并使用全局 `dashboard.css`，尚未迁到实施包目标 `features/dashboard` 的局部样式边界，因此不能标记旧CSS退出。

## 浮层结论

首页没有自有对话框、抽屉或编辑层。模块、家庭场景和账户按钮打开的界面分别归目标模块、家庭F-20和账户O-22管理；O-01记录为不适用，防止重复计算同一浮层。
