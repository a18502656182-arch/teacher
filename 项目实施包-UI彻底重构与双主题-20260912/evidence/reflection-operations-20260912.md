# 考试反思操作核验（2026-09-12）

范围：F-12 / O-12。证据基于当前源码、纯操作测试和本地 Chromium/CDP 演示工作区；不证明独立校园反思页完成，也不证明线上已更新。

## 源码发现

- 桌面与手机各自拼装反思和沟通记录，主要问题校验、`classId/studentId` 快照及日期不一致。
- 每次点击完成都会创建新的沟通记录，同一反思反复编辑会留下重复台账。
- 反思列表只按当前学生 ID 过滤，没有同时核对显式班级和考试归属。
- 手机默认考试直接取全局第一场，切换班级后可能保留上一班考试 ID。
- 部分成绩在反思页显示成零分总分，和成绩分析已确立的“未录不等于零分”语义冲突。
- 演示/只读模式由工作区 `update` 拦截，但原页面仍会关闭手机编辑器并显示完成成功文案。

## 已修改

- 新增 `features/reflections/operations.ts`，提供当前班列表、日期、归属判断和草稿/完成保存。
- 新增 `CommunicationRecord.reflectionId` 可选关联，完成留痕从重复追加改为稳定更新一条；内容明确为内部学生复盘及家长沟通建议，没有外发行为。
- 草稿与完成分别处理重点跟进；只有完成才移除当前学生，另一班考试、学生、反思和记录不变。
- 桌面、手机和评语依据读取统一使用当前班反思；手机班级切换同步有效考试。
- 页面按完整、部分、未录三种状态显示成绩；只读操作保留当前输入和编辑器。
- `scripts/layout-audit.mjs` 增加反思编辑器、五个长文本字段、只读提示和失败后草稿保留的真实浏览器断言。

- 新增 8 项纯操作回归：两班各 50 人过滤、草稿、完成、跟进移除、重复完成幂等、空字段/跨班拒绝、关联稳定、旧无考试记录和本机日期。
- `npm test`：生产构建、112/112 自动化测试和认证集成通过。
- TypeScript、相关 ESLint 及全站 19 模块 × 6 宽度 `qa:strict` 通过；严格结果仍为静态项加 114 个模块/宽度组合，共 115 项，失败 0。
- 单页截图与交互覆盖 1440、1280、1057、768、390、360；只读完成后编辑器、五个文本字段、合成输入均保留，未发现运行时错误或横向溢出。
- 构建仍报告前端 chunk 超过 500KB，`ClassroomApp.tsx` 的 ESLint 转换也提示文件过大。

## 未完成边界

- 生产反思页面仍使用旧 `reflection5-*` 和手机共用大组件，校园构图、局部 CSS、统一 controller 和旧 CSS 退出尚未实施。
- 桌面切换学生、考试库关闭、手机关闭/背景退出没有脏草稿确认；普通保存失败只能从全局工作区草稿恢复，不能恢复具体弹层位置。
- 本轮真实浏览器写操作只验证只读拒绝。可写账号的服务器确认、409、重复点击期间的保存中状态和外部手机网络未重新执行。
- 旧版重复沟通记录没有安全的确定性匹配条件，因此不自动清理；只有新关联建立后的重复完成具备幂等保证。
- 未操作正式数据库、线上服务或部署包。
