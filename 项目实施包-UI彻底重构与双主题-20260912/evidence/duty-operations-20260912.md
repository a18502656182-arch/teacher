# 值日岗位完整迁移核验（2026-09-12）

范围：F-18 / O-18。实现提交：`50f88c3`。证据来自当前源码、纯操作测试、只读演示工作区与系统临时目录中的隔离合成可写工作区；不代表线上部署或生产数据库验收。

## 审计发现与实现

- 旧桌面和手机值日分别维护操作与界面，岗位、轮换序号主要依赖根 `dutyJobs` / `dutyOffset`，切班可能沿用另一班固定学生；每个星期还曾写入同一个“今天”日期。恢复自动安排会删除整条检查记录，连同状态与备注一起丢失；旧手机分支没有一致执行只读限制。
- 新增 `Duty.tsx`、`Duty.module.css` 和 `features/duty/operations.ts`。桌面与手机现在渲染同一业务页面，含岗位检查、本周安排、岗位设置、检查台账四个视图；旧 `duty3-*` 和 `mobile-duty-*` DOM 已从生产组件移除。
- `classDutySettings[classId]` 成为岗位和轮换序号的班级映射，根字段只承担活动班兼容。归一化会过滤不属于该班的固定学生；新班不会继承上一班岗位。删除学生时只清理目标班固定名单和相关值日记录，不触碰另一班。
- 教学日读取当前班课程日程，支持六天或七天及星期别名；每个教学日换算当前自然周的真实本地日期。自动轮换只使用有学生的实际组号，非连续组号可用，未分组学生会明确提示且不进入自动分配。
- 分配来源区分自动、固定和临时。检查会保存当日岗位、负责人姓名/ID、组号和来源快照；轮换不追改已检查记录。恢复自动只替换负责人快照，保留既有完成/返工状态与备注。岗位、记录和备注写入均校验班级、学生、岗位与日期。
- 完整备份替换期间另发现班级作用域同步仍可能用旧班映射覆盖导入数据。`scopeClassSettings` 已改为合并导入映射、清理被移除班级，并仅在原活动班仍存在时保留它的兼容字段；旧备份迁移路径继续保留。
- 值日页新增独立 `duty` 主题插画槽和 `duty-cleaning.webp` 水彩素材，内容为检查板、清洁工具、书本与绿植，无人物、宠物、口号或可读文字；玻璃主题仍为空槽且没有用户入口。
