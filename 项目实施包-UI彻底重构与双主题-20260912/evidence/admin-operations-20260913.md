## 功能保全与新入口

| 行为 | 新入口与结果 |
| --- | --- |
| 管理员会话 | `/admin` 保持独立管理员登录、会话检查和退出；错误密码保留表单，网络错误显示中文重试信息。 |
| 账户检索 | 用户页支持手机号、班级、状态检索和25条分页；顶部账户总量不随当前筛选错误收缩。 |
| 账户详情 | 同一个原生对话框展示账户状态、班级、期限、工作区模式和有效设备数量。 |
| 手机号 | 编辑时校验11位手机号；重复号码由服务端返回409，失败保留编辑器，关闭脏表单需确认。 |
| 设备 | 列出设备名称、最近使用和状态；解绑需内联确认，成功后只撤销目标设备及其会话。 |
| 续期与状态 | 续期30天、禁用和恢复均需内联确认；结果以服务端响应为准，取消不写入。 |
| 数据导出与永久删除 | 导出真实服务端JSON；永久删除要求输入账户当前完整手机号，错误输入不能执行，成功后兑换码禁用并写审计。 |
| 兑换码 | 支持一次生成1至50个、6至8位、1至3台设备、有效期、尾号/状态/手机号检索、分页、复制和启停。复制只有浏览器确认成功后才提示。 |
| 审计 | 展示管理员操作、对象、来源和时间；设备解绑、改号、续期、导出、永久删除均由服务端写审计。 |

## 展示层与主题边界

- `/admin` 只保留薄入口，页面、对话框、状态和请求分别进入 `features/admin`；旧页面内联控制器和全局 `admin.css` 已删除。
- 新页面使用页面级 CSS Module、共享原生 `Dialog`、统一 SVG 图标和 `admin` 主题插画槽。校园主题接入原创课程规划插画；玻璃主题映射为空，界面没有未完成的切换入口。
- 桌面 1280×720 使用标题场景、稳定摘要、任务导航和数据表；手机 390×844 使用同一业务树，表格转为带字段标签的列表，对话框主体独立滚动且页脚操作可达。
- 30条兑换码验证分页为25+5；筛选无结果时不再误报“尚未生成兑换码”。断开本地服务后，已加载行和检索字段保持，页面显示可重试错误。

## 实际渲染与交互

- 桌面和手机均验证登录、错误密码、空用户、空兑换码、30条长列表、分页、复制反馈、启停、账户详情、手机号校验与保存、设备列表、解绑取消、续期取消与确认、禁用与恢复、导出、永久删除确认输入、审计列表和网络失败保留。
