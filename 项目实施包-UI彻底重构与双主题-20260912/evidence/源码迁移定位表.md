# 源码迁移定位（目标路径拟建）

以 source-symbol-index.json 当前行号辅助定位；后续代码变化用符号查找，不依赖旧行号。

|当前入口/符号|拟迁入|保持的关键语义|
|---|---|---|
|ClassroomApp normalizeData/scopeClassSettings|lib/workbench/normalization.ts|旧字段兜底、当前班级数据投影|
|removeStudentRelations/updateClassStudents|lib/workbench/studentRelations.ts|跨模块关联清理、classId归属|
|save/commitWorkspace/loadLatestWorkspace|features/workspace/useWorkspaceController.ts|ref、队列、409、草稿、服务端确认|
|getScheduleWeekDates/日期帮助|lib/workbench/scheduleDates.ts|原日历和学期计算|
|scoreRowsFor/scoreTotal等|lib/workbench/scoreSelectors.ts|缺失/零分/满分/等级口径|
|Students/MobileStudents|features/students/controller.ts+视图|一套编辑/导入/删除和选择状态|
|Homework/MobileHomework|features/homework/controller.ts+视图|任务范围、批量、跟进复制|
|Scores/MobileScores|features/scores/controller.ts+视图|考试/科目和分析接口|
|MobileSecondaryPage分支及对应桌面函数|各features模块|逐分支操作并集，不能只迁桌面|
|dictation/*.tsx|features/dictation或原模块内新view|保留lib/dictation与commit协议|
|WorkspaceChrome/ClassSwitcher|components/workbench/shell|19导航、班级管理、保存状态|
|DialogAccessibility/StudentLookupDialog|components/workbench/ui|焦点栈、只一个管理器、搜索分页|
|workbench-repair.css+校园覆盖CSS|各组件CSS Modules+theme token|所有消费者迁移后移除导入|
|layout-audit+rendered-html tests|同文件更新测试目标|不保留空旧文件、不降低风险覆盖|

目标路径可以调整；不能为了符合表名把运行逻辑切坏。API/DB默认不变。源码副本未纳入包，避免下一对话从过期副本继续开发。
