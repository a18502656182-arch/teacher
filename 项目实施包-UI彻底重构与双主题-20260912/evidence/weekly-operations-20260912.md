# 班级周报操作核验（2026-09-12）

范围：F-13 / O-13。证据来自当前源码、纯操作测试和本地 Chromium/CDP 演示工作区；不证明独立校园周报页完成，也不证明线上更新。

## 发现与修改

- 原手机保存无论意图都会写“已归档”，只读时页面更新被根层阻止，但编辑器仍可能关闭并显示成功。
- 原自动汇总把无日期积分/沟通和学生当前成绩、考勤、作业状态塞入所选历史周，并生成没有事实来源的表扬理由。
- 新增 `features/weekly/operations.ts`；桌面与手机共用班级过滤、草稿/归档保存、作业记录指标、带日期积分、正向名单和本周跟进计算。
- 作业缺失状态不再用当前学生汇总填补；不同满分考试按得分率计算，未录不算零分；无日期旧事实不归入任意周。
- 同班同周同版本稳定更新，跨班、重复目标、空正文和非法日期均拒绝；旧无 `classId` 周报只在载入时归当前活动班。
- 手机编辑器补齐草稿与归档两个入口，失败保留草稿；人工截图发现并修复粘性动作重叠、半宽主操作与只读 toast 覆盖。

## 验证

- `tests/weekly-operations.test.mjs`：10/10，通过两班各50人、家庭隔离、保存、冲突、缺失状态、日期证据、成长/沟通合并、正向聚合、考试满分和考勤用例。
- 完整 `npm test`：生产构建、122/122 自动化测试、认证集成通过。
- TypeScript、相关与全量 ESLint 通过；构建仍有已知前端 chunk 超过500KB警告。
- `qa:strict` 在19模块×6宽度的完整运行及周报定向复验均通过；定向复验截图覆盖1440、1280、1057、768、390、360。
- 浏览器自动输入 `QA周报只读保留内容`，点击保存草稿后确认编辑器、两个长文本字段、只读提示和输入仍在；手机主归档动作占满编辑器宽度。

## 边界

- 当前页面仍使用旧 `weekreport-*` 和 `MobileSecondaryPage` 结构，不能登记 A-13 视觉通过或旧 CSS 退出。
- `weeklyPlan` 仍是工作区共享值，没有班级/学期归属；本轮未擅自迁移数据模型。
- 关闭、切周和切版本无脏提示；普通服务器失败只保留全局工作区草稿，手机不能恢复具体底部层；没有保存中防重复。
- 源码没有周报专用文件导出；复制只表示剪贴板成功，不是外部发送。
- 没有使用可写正式账号，没有操作生产数据库、服务器或部署包。
