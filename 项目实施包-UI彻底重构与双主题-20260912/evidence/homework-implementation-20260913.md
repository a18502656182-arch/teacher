# TASK-14 作业构图基准证据

## 结果

作业页已迁入独立 `features/homework` 视图、统一控制器、纯读取模型和局部 CSS Module。桌面是一张连续批改工作纸：左侧 330px 任务主列表，右侧集中显示当前任务事实、异常筛选、逐生四态、完整备注和选择后出现的批量操作。手机不压缩双栏，而从任务列表进入学生处理 Drawer。

## 功能保全与边界

- 新增、编辑、删除任务；日期、学科、内容必填，字段错误就近显示，脏关闭使用共享放弃确认。
- 任务检索、学科和高级月份/日期/学生状态/小组筛选，任务每页 10 项；学生姓名/学号/备注、状态、小组筛选，学生每页 20 人。
- 已交、未交、待订正、已复查四态支持逐生与批量；批量栏仅在选中学生后出现，成功本地应用后清空选择。
- 公共学生备注完整可编辑；待跟进名单支持加入、移出、查看与复制，复制失败留在当前层并提示。
- 所有任务按显式 `classId` 限定当前班，学生来自活动班名册；学生搜索不包含家长电话。演示和到期只读保留查询、查看与复制，禁用写入。
- 页面更新继续进入共享 workspace 本机草稿；网络失败与 409 保留 dirty/草稿并由全局重试或冲突流程处理。没有修改 API 或数据库。

## 验证

- `npm test`：生产构建、251/251 自动化和认证集成通过；构建仅有既知的大于 500KB chunk 警告。
- `npx tsc --noEmit --pretty false --incremental false`、`npm run lint`、`npm run qa:layout`通过。
- `npm run qa:strict`：1440×900、1280×900、1057×900、768×1024、360×780、390×844 六档真实 Chromium 审计通过；自动进入手机详情、选择学生、验证批量栏和只读禁写，并从任务菜单打开待跟进名单。
- 1536×1024 与 390×844 实际浏览器检查无整页横向溢出；截图位于本机临时目录 `task14-homework-desktop.png`、`task14-homework-mobile.png`，不提交个人路径证据。
- Impeccable detector 仅发现 21px/24px 偏离既有字阶的 advisory，已机械收敛为 20px/22px；没有把新字号写入设计系统。
- 独立完成度初审发现 1057/1280 紧凑桌面学生行会被最小内容宽度撑开，以及组合学生筛选可由不同学生分别命中；已将紧凑桌面学生行改为两行，并把关键词/状态/小组合并到同一学生谓词，新增回归后复审。
- 独立复审结论为 `PASS`：两项初审问题均闭环，1057/1280 的五项指标、三个学生筛选、四态快捷处理和完整备注全部可达，没有剩余 material finding。
