# 代码样例使用说明

examples/contracts.ts.txt：拟议共享主题与操作接口，文本后缀避免进入项目tsconfig。不声称已经适配现有React/服务端代码。
examples/theme-tokens.css.txt：语义token起点，校园default；玻璃仅内部示意。需在实际组件检查读色、对比度和fallback。
examples/save-transition.mjs：纯函数状态机教学样例，不发请求，不写数据库。只说明保存失败不跳人与主题事件不改编辑状态；不替代现有save队列/版本判断。
examples/save-transition.test.mjs：验证样例自身的边界，非项目业务回归。
examples/fixture-spec.json：合成数据规格，不是有效ClassroomData/备份，必须由当前schema工厂实现。
examples/migration-boundary.md：新旧样式隔离与React生命周期注意事项。

运行样例检查：在项目根目录执行 node --test 项目实施包-UI彻底重构与双主题-20260912/examples/save-transition.test.mjs 。
本包无实际React成品页面，避免下个对话将示意控件直接作为最终视觉成果。生产素材要在M1确定容器后生成，不默认复用旧小图。
